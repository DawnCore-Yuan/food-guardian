### 桌面與手機檢視

- 桌面 1280×720：四敵人＋警告三角＋玩家彈＋敵彈同框，輪廓清楚
- 手機比例 844×390（canvas 693×390）：角色與彈體仍可辨識

已發現、**本批未修**的問題（屬「背景與辨識度」議題，待你決定）：

1. **背景地面反光偏亮**（輸送帶與地板中央的白亮區域），在上半部外仍有 2 處明顯亮斑，對細小的 12×12 敵彈造成對比壓力。
2. **背景細線密度**（管線、通風格柵）與敵彈尺寸接近，紫色敵彈在淺藍底上尚可辨，但在亮面區域對比下降。
3. 警告三角顏色（橙黃）與金黃色系敵人（黃麴毒素、葡萄球菌）在淺底上對比偏低。

### 特效尺度修正（追補）

初次截圖時特效「看不出來」，追查後發現不是沒播放，而是：

1. 命中火花在 160ms 內就淡出，截圖取樣時機常落在 alpha 0.1 以下
2. 放大幅度過大（1.15／1.35 倍）在近距離會蓋到旁邊的敵人

修正：放大收斂為 1.04／1.08 倍，時間縮為 160／300ms，只做淡出為主。
驗收：`artifacts/d2-fx.png`、`artifacts/d2-mobile.png`、`artifacts/d2-fx-sequence.png`。

> 方法論紀錄：這次一度誤判為「特效完全沒被繪製」，實際是單張截圖拍在淡出尾端。
> 後續驗證特效，必須以「物件存在 + alpha/scale 序列」與「時序多拍」兩個證據交叉。

## 批次 3 — 辨識度優化（2026-10-21）

### 一、背景（重製自原稿，不是疊濾鏡第二次）

以 `docs/art-source/bg-factory-source.png` 重新縮放到 1280×720 後處理：

| 步驟 | 參數 | 目的 |
|---|---|---|
| 降飽和 | 向灰靠 22%（保留 78%） | 減低色彩搶眼 |
| 降局部對比 | 以 3px 模糊層為基準，細節衰減至 70% | 線條不與敵彈混淆，大形狀保留 |
| 地板反光 | 18px 模糊亮度 >210 的區域滾降，最多 -22% | 壓低過亮反光，不做整張壓暗、不加白霧 |

**B. 跨 Scene 順序（不靠 depth 比較）**

實測 `game.scene.scenes`：Boot, Menu, Game, Hud；`getScenes(true)`：Game, Hud。

- Scene 清單順序 Hud 在 Game 之後 → HudScene 整層繪製在 GameScene 之上。
- 這是 scene 順序決定的，不是 depth。HudScene 內部的 depth 數值與 GameScene 的 depth 數值不可互相比較。
- 因此背景（-10）與火花（7）只影響 GameScene 內部；HUD 與文字在獨立 scene，不受背景對比調整影響。
