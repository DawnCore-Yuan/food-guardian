## 3. 資產分層（重要）

**高解析原稿與執行期素材分開保存。**

```
docs/art-source/           ← 高解析原稿（不進 build）
  player-source.png
  enemy-aflatoxin-source.png
  ...

public/assets/sprites/     ← 執行期素材（等比整理後的遊戲尺寸）
  player.png               (64×40)
  enemies/aflatoxin.png    (72×72)
  ...
```

**處理流程**：

1. 原稿保留在 `docs/art-source/`，不改動
2. 用 Chromium Canvas 等比縮放至表列遊戲尺寸，輸出 PNG 到 `public/assets/sprites/`
3. Phaser 以 **scale = 1** 載入執行期素材，不使用 512×320 原稿直接縮放
4. 縮放時保持長寬比（`min(targetW/srcW, targetH/srcH)`），**禁止拉伸**

## 5. 透明度與完整性檢查（收到後執行）

**不只看角落。** 檢查項目：

| # | 檢查 | 方法 |
|---|---|---|
| 1 | 是否真有 alpha 通道 | 讀 PNG 色彩類型 |
| 2 | 背景是否透明 | 統計非角色區域的 alpha 分布，確認整片 alpha=0 |
| 3 | 是否烘焙棋盤格 | 檢查灰白交替像素是否存在於應透明區 |
| 4 | 角色可見範圍 | 計算 alpha>0 的 bounding box |
| 5 | 四周留白 | bounding box 與畫布邊界的距離 |
| 6 | 是否被裁邊 | 檢查 bounding box 是否貼齊畫布邊（貼邊視為可能裁切） |
| 7 | 關鍵特徵完整 | 沙門氏菌鞭毛、黃麴毒素霧環、二氧化硫結晶、球群四球 |

**允許**：角色本身的光影與立體陰影。
**排除**：背景投影（角色外圍的灰色柔邊陰影）。

發現問題時**列出實際觀測**（哪個邊、缺什麼），由曉杰重新生成，不由我硬修冒充完成。

## 8. 接入流程（收到素材後）

1. 原稿放入 `docs/art-source/`
2. Canvas 檢查透明度與完整性（第 5 節）
3. 等比縮放至第 4 節尺寸，輸出到 `public/assets/sprites/`
4. 建立 `public/assets/CREDITS.json`（來源、授權、是否修改）
5. 改 `placeholder.ts`：**有圖用圖，無圖退幾何佔位**
6. **不改** `body.setSize()` 的既有值
7. 實測所有角色的世界碰撞體與置中
8. 出並排預覽與遊戲內截圖，逐項標明「已接入／仍是佔位」
